# SeerHub

Problema:

Neste momentos existem vários sitios onde Tipsters partilham as suas apostas, seja Patreon, BuyMeACooffe,Telegram, etc. A minha ideia era criar um Hub, onde cada pessoa podia criar a sua comunidade, gerir o preço das subscrições e partilhar as suas tips. Desta forma um utilizador final poderia simplesmente aceder a informação de multiplas comunidades num so sitio.

Requisitos:
Um utilizador deve poder criar um comunidade e definir os preços das subscrições
Um utilizador deve poder entrar em várias comunidades
Deve haver um Hub, onde é displayed toda a informação das comunidades
Deve haver um sistema (AI?) que permite o dono da comunidade inserir um texto com todas as suas previoes e tips e este texto deve ser automaticamente organizado em tips estruturadas e com display visual, basicamente o utilizador apenas da input a um texto em vez de adicionar 1 por 1 tip
Deve ser possivel haver um chat dentro da aplicação, por comunidade e entre utilizadores
Deve ser possivel haver uma aba de estatisticas para perceber se o tipster esta a fazer um bom trabalho
Deve haver um sistema de permissoes e autorizações para entrar em determinadas paginas (se estas na comunidade, etc)
Deve haver 3 possiveis "ecras", dono de uma comunidade, utilizador final, ou ADMIN
Se possivel ter acesso aos nomes e embelemas das equipas(API Publica? Parecido com o Flashscore ou Sofascore)
O dono de uma comunidade deve conseguir adicionar alguem como "Moderador" da comunidade onde pode ser alguem que tambem consigo partilhar tips e assim
Deve haver um sistema de notificações quando alguem posta algo na comunidade


Spring + React + Postgres - Uso de containres docker
